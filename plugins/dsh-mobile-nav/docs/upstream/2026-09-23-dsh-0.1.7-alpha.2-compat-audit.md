### 1.1 唯一一条改动：`_dialog_w1urq_22` → 结构化 marker

- 实情：`_root_w1urq_2` / `_dialog_w1urq_22` 这一族哈希在 **alpha.1 与 alpha.2 上都已消失**（`grep -rl w1urq` 两版均 0 命中）。
- 插件是否依赖它：**不依赖**。`base.css.ts` 里那条 z-index 规则用的是结构化选择器
  `body:has([data-mobile-nav="frame"]:not([data-sidebar-collapsed])) > div:has(> [role="dialog"][aria-modal="true"])`，哈希只出现在注释里（注释已同步改成"只锚形状，别再写回哈希"）。
- 契约表处置：条目改 `kind: "marker"`，needle 换成插件真正依赖的形状
  `body > div:has(> [role="dialog"][aria-modal="true"])`（探针对 marker 走 `querySelector`，对 hash 走文本子串）。

## 4. 本机没验到的（照实记，别当已验）

1. **CDP 契约电池**：`node scripts/cdp-compat-contracts.mjs`（`miss=0`）、`pnpm smoke:cdp`（`new=0`）、
   `cdp-swipe-failures.mjs`、`cdp-zoom-probe.mjs`、`scripts/probes/*.mjs` —— 都需要 chromium，容器里没有。
2. **多宽度/平板**：`scripts/probes/multi-width-layout-probe.mjs`（本次新增，覆盖 320/360/390/430/768/1023/1280）。
3. **字体缩放（Android fontScale）**、**折叠屏跨 768 档**：CDP 无对应 emulation，需真机。
4. 复验顺序仍按 `upgrade-runbook.md` §4 的电池执行；`pnpm` 在本容器不可用（store 缺 `pnpm.mjs`），
   等价命令为：`node_modules/.bin/tsc -p tsconfig.json` → `tsc -p tsconfig.client.json` →
   `node scripts/build-client.mjs` → `node --test tests/*.test.ts`。
