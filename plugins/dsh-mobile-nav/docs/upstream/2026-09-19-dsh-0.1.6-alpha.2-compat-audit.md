## 1. 实锤会撞的（升级 0.1.6 前必须适配/验证）

### 1.1 ContextMeter 迁移（用户真机观察，源码实锤）

- `ui-conversation/src/client/skeleton/InputBar.tsx`：`<ContextMeter/>` 从 tools 行（发送按钮旁）移出，放入卡片下方**新 `css.dock` 条**，与 `conversation.composer.dock` 槽位同容器——即用户说的「输入框下方滑动栏」。
- `ContextMeter.tsx`：注释 "a ring **beside the send button**" → "a ring **and percentage below the card**"；新增百分比读数 `<span>{reading}</span>`；分解面板改 `createPortal(…, document.body)` + 新 primitives `useAnchoredPosition`/`useDismissOnOutsidePointer`（body 级浮层，`role="dialog"` 非 aria-modal）。
- `ContextMeter.module.css`：28px 圆环按钮（"Same 28px circular hit target family as the composer's attach button"）→ **带百分比的 pill**（inline-flex、13px、tabular-nums）。
- **对本插件的冲击点**：
  - `JObwrW_`（ContextMeter，compat-contracts `contextmeter`）——右簇钉住规则的依赖对象 DOM 位置变了；类名存活（dist 普查 HIT）但位置语义变了，`misc`/`compat` 里 composer 右簇规则要重审。
  - body 级 portal 浮层会逃出抽屉手势的 DOM 层级 → `gesture-guard` 的 host-yield 消费标记与「backdrop 误吞」族需要把它当新浮层族对待；Escape 让位判定（`[aria-modal="true"]` 契约）不含 `role="dialog"` 非 modal 面板，需真机验证 Escape 优先级。
  - Composer dock 条现在是「dock 槽位 + meter」双内容，移动端 `composer 行`/`hero 净空` 适配要按新结构重排。

### 1.2 Composer tools 行内容变化

- **回形针 attach 按钮删除**（`file.attach` Tooltip+button 从 tools 行移除；`input[type=file]` 仍在，入口合并进 "+"）——`composer 行` 契约（发送/停止/+ 三件套，PR #48 keepFocus）的按钮集合变了，`composer-keyboard-guard` 的目标清单要重对。
- **新增 `conversation.input.permission` 槽位**进 tools 行 modes（与 plan 并排）；`PermissionSelect` 整体从 ui-conversation 迁到 `ui-permission-presets`（R081）→ 移动端 tools 行更挤，`preset 菜单`/`header 拥挤` 族坑位风险 +1。
- `ComposerBarInjected` 移除 `command` 字段（类型层破坏，本插件未用，无直接影响）。

### 1.3 Slot 架构重构（SlotFactoryMap）

- 新 `conversation.content` **Factory**：`variant: 'main' | 'embedded'` + `phase` + 每 occurrence 的 `widthControls`（`ConversationWidthControls.tsx` 新增，会话宽度可调手柄）——Conversation 可被嵌入实例化，主面板形状不再是唯一形态。
- 契约漂移：`conversation.session` 加 `owner: { view?: string }`；`conversation.composer.bar` scope `session`→`session-maybe`；`conversation.hero.agentPreset` scope `root`→`session-maybe`；`conversation.composer` 进 factory children 表。
- **本插件两个槽位存活**：`conversation.session.header.actions` 与 `sidebar.footer.action` 在 a2 声明中原样保留（diff 未触及）✔。
- 新槽位（无人认领，不影响现有）：`conversation.session.header.leading`、`conversation.input.permission`、`sidebar.toggle.badge`。
- `client-ui-slots` 类型面新增 `PropsRenderFactories`/`FactoryComponentPropsOf`/`FactoryLocalComponentPropsOf`——本插件 type-only import 的 `SlotMap` merge 键未动，但升级后 `pnpm verify`（类型层）是第一道门。
